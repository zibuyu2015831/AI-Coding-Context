## 🌍 文档语言确认 (必须)

### 语言确认优先级

```
1. config/user_config.md 中的 documentLanguage (最高优先级)
   ↓
2. 询问用户选择
   ↓
3. 默认值: zh-CN (中文)
```

### 执行流程

**步骤 1: 检查配置文件**

```bash
# 读取用户配置中的 documentLanguage
if config/user_config.md 存在:
    读取 frontmatter 中的 documentLanguage
    if documentLanguage 有效:
        使用配置的语言,跳过询问
    else:
        继续步骤 2
else:
    继续步骤 2
```

**步骤 2: 询问用户(仅当配置不存在时)**

```markdown
📝 在开始生成文档体系前,请确认:

**您希望生成的文档使用什么语言?**

A. 中文 (推荐,默认)
B. 英文  
C. 日语

请回复 A / B / C

注意: 您的选择将保存到 config/user_config.md,下次无需重复配置
```

**步骤 3: 保存用户选择**

用户首次选择后:

1. 如果 config/user_config.md 不存在,从 CONFIG_TEMPLATE.md 复制
2. 更新 frontmatter 中的 documentLanguage 字段
3. 保存文件

## 📋 处理规则

1. **默认值**: 如果用户没有明确选择,**默认使用中文**

2. **影响范围**: 所有生成的文档都使用用户选择的语言

   - `dev_docs/AI_Coding_Context.md` (主文档)
   - 所有子文档
   - `knowledge/` 目录下的知识库
   - `plans/` 目录下的方案文档
   - `dev_docs/rules/combined/AI_RULES.md` 规则文件

3. **代码注释**: 代码示例中的注释也使用相应语言

4. **变量命名**: 遵循该语言习惯
   - 中文: 可在注释中使用中文说明
   - 英文: 注释使用英文
   - 其他语言: 根据用户指定

---

## 🕐 询问时机

**必须在步骤 0(环境预检)之前询问**

原因:

- ✅ 避免重复工作 - 如果先生成再改语言,需要重新生成
- ✅ 上下文一致 - 确保整个生成过程使用同一语言
- ✅ 提升效率 - 一次性确定,不需要中途切换

## 📝 示例对话

### AI 询问

```markdown
📝 在开始生成文档体系前,请确认:

**您希望生成的文档使用什么语言?**

A. 中文 (推荐,默认)
B. 英文  
C. 其他语言 (请指定)

请回复 A / B / C-[语言名]
```

### 用户回复示例

**示例 1**: 用户回复 "A" 或 "中文"

- AI 使用中文生成所有文档

**示例 2**: 用户回复 "B" 或 "英文" 或 "English"

- AI 使用英文生成所有文档

**示例 3**: 用户回复 "C-日语"

- AI 使用日语生成所有文档

**示例 4**: 用户未明确回复

- AI 默认使用中文,并在开始时确认:"将使用中文生成文档"

## ✅ 检查清单

生成文档前,AI 必须确认:

- [ ] 已询问用户文档语言偏好
- [ ] 已获得用户明确回复或使用默认值(中文)
- [ ] 已在生成计划中注明使用的语言

生成过程中,AI 必须确保:

- [ ] 所有文档使用一致的语言
- [ ] 代码注释使用指定语言
- [ ] 示例说明使用指定语言

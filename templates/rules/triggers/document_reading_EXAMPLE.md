## 文档阅读触发器

### 根据任务类型自动阅读对应文档

| 任务关键词                  | 触发阅读文档                          | 阅读时机       |
| --------------------------- | ------------------------------------- | -------------- |
| API、接口、请求、fetch      | `dev_docs/api_layer.md`               | 编写API调用前  |
| store、状态、pinia、vuex    | `dev_docs/state_management.md`        | 使用状态管理前 |
| 组件、component、vue        | `dev_docs/component_guide.md`         | 创建组件前     |
| 路由、router、导航          | `dev_docs/routing_guide.md`           | 修改路由前     |
| 样式、css、style            | `dev_docs/styling_guide.md`           | 编写样式前     |
| 表单、form、validation      | `dev_docs/form_validation.md`         | 处理表单前     |
| 错误、异常、error           | `dev_docs/error_handling.md`          | 处理错误前     |
| 性能、优化、performance     | `dev_docs/knowledge/performance/`     | 优化性能时     |
| 问题、解决、troubleshooting | `dev_docs/knowledge/troubleshooting/` | 遇到问题时     |

### 触发优先级

1. **先检查knowledge/** - 同类问题可能已有解决方案
2. **再查阅对应子文档** - 获取详细规范和示例
3. **最后查看主文档** - 了解整体架构和上下文

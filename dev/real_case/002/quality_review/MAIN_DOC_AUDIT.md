// 核心函数: 查找Git根目录
const findGitRoot = () => {
  // 从当前目录向上查找.git目录
  let currentDir = process.cwd();
  
  while (currentDir !== path.dirname(currentDir)) {
    if (fs.existsSync(path.join(currentDir, '.git'))) {

5. **禁止同步阻塞操作**:

   - 原因: 防止栈溢出

   - ❌ 不要使用标记为 @deprecated 的API

- 没有自动化检查工具验证模板合规性

**教训**: 必须建立模板合规性检查机制

---

### 教训2: "有"不等于"好"

**问题**: 有些章节虽然存在，但质量不够

**案例**: 
- 核心代码模式：有代码但缺少注释
- 命名规范：有基本规范但不够全面
- 业务模块映射：有表格但不够详细

**教训**: 不仅要检查"有没有"，还要检查"好不好"

---

### 教训3: 主文档是用户的第一印象

**重要性**: 主文档是用户接触框架的第一个文档

**影响**: 
- 缺失的章节会让用户困惑
- 不完整的信息会降低用户信心
- 质量问题会影响整个文档体系的可信度

**教训**: 主文档的质量标准应该最高

## 📋 实施概览

### 核心目标
实现文档阅读习惯引导机制，包括：
- 智能文档推荐（基于摘要和用户任务）
- 理解偏差检测与主动提醒
- 功能开关配置（与 016 配置系统集成）
- 推荐频率控制

### 技术架构
```
014 文档阅读习惯引导机制
├── AI 角色库
│   ├── document_recommender.md (文档推荐专家)
│   └── understanding_guardian.md (理解偏差检测专家)
├── 配置系统集成
│   └── CONFIG_TEMPLATE.md (新增 doc_reading_guide 配置)
├── AI_RULES 模板
│   └── AI_RULES_TEMPLATE.md (新增推荐和检测规则)
└── 核心入口文档
    ├── README.md (新增使用说明)
    ├── AI_ENTRY_POINT.md (新增功能说明)
    └── AI_Coding_Context_TEMPLATE.md (新增阅读指导)
```

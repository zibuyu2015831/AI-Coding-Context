# 框架边界优化方案

## 📋 目录说明

本目录存放框架边界问题的优化方案及相关文档。

## 🎯 优化目标

解决 AI 在使用框架时，将框架本身误认为用户项目代码的问题，确保：

- AI 能清晰区分"工具"（框架）与"目标"（用户业务代码）
- 项目分析数据准确（文件数、代码行数等）
- 文档生成内容不包含框架自身文件

## 🔑 关键特性

### 智能框架检测

通过脚本位置（`__file__`/`__filename`）反推框架根目录，支持框架任意重命名：

```python
# 即使用户将框架重命名为 my_custom_ai_tools
# 工具仍能自动识别并排除
detect_framework_dir(root_dir, __file__)
```

### 三层防护策略

1. **入口文档声明**（`AI_ENTRY_POINT.md`）
   - 明确框架边界和排除规则
2. **工作流强化**（`path_a_first_generation.md` 等）

   - 在关键步骤重复提醒

3. **工具默认排除**（`project_scanner.py/js`）
   - 工具层面自动过滤
   - `--exclude-standard` 一键排除

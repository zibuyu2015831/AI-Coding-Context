# 项目扫描工具优化方案总结

## 📋 方案核心

基于用户需求,设计了一个**智能自适应**的项目扫描输出优化方案,核心特性:

### ✅ 已确认的设计要点

1. **保留现有模式**: 文件树模式继续作为默认选项,向后兼容
2. **新增摘要模式**: 提供轻量级的项目概览
3. **智能三级分级**:
   - **初级** (0-500 文件): 完整输出
   - **中级** (501-2000 文件): 省略文件,保留完整目录结构
   - **高级** (>2000 文件): 目录和文件都省略,但有智能子判断
4. **自动评估**: 无论用户选择哪种模式,都先扫描生成摘要,自动评估复杂度
5. **灵活控制**: 提供多个参数让用户精细调整行为

---

## 🎛️ 新增参数一览

| 参数                       | 类型   | 默认值  | 说明                                      |
| -------------------------- | ------ | ------- | ----------------------------------------- |
| `--mode`                   | choice | `auto`  | 输出模式: tree/summary/auto               |
| `--complexity-override`    | choice | 无      | 手动指定复杂度级别: basic/medium/advanced |
| `--limit-items`            | int    | `10`    | 中级/高级模式下每目录最多显示的项目数 ⭐  |
| `--no-adaptive`            | flag   | `false` | 禁用自适应机制,始终输出完整文件树 ⭐      |
| `--advanced-dir-threshold` | int    | `20`    | 高级模式下子目录数量阈值 ⭐               |

> ⭐ 标记为用户新增需求

---

## 🎯 三级策略详解

### 初级 (Basic)

- **触发条件**: 0-500 文件
- **策略**: 完整输出,不做任何省略
- **Token 消耗**: 2,000-5,000 tokens

### 中级 (Medium)

- **触发条件**: 501-2,000 文件
- **策略**:
  - ✅ 保留完整目录结构
  - ✅ 每目录最多显示 N 个文件 (由 `--limit-items` 控制,默认 10)
  - ✅ 超出部分显示 `"... (省略 X 个文件)"`
- **Token 消耗**: 约 8,000 tokens (节省 68%)

### 高级 (Advanced)

- **触发条件**: >2,000 文件
- **策略**:
  - ✅ 每目录最多显示 N 个子目录 (由 `--limit-items` 控制,默认 10)
  - ✅ 每目录最多显示 N 个文件 (由 `--limit-items` 控制,默认 10)
  - ⭐ **智能子判断**: 如果某目录的子目录数量 ≤ `--advanced-dir-threshold` (默认 20)
    - 保留所有子目录名称
    - 但省略子目录内的文件,仅显示 `"(X files)"`
- **Token 消耗**: 约 12,000 tokens (节省 85%)

---

## 💡 智能子判断示例

### 场景 A: 子目录数量超过阈值 (正常省略)

```
src/ (35 个子目录)
├── components/
├── utils/
├── hooks/
├── services/
├── types/
... (省略 30 个子目录)
```

### 场景 B: 子目录数量未超过阈值 (智能保留)

```
config/ (5 个子目录)
├── env/ (12 files)
├── webpack/ (8 files)
├── babel/ (3 files)
├── eslint/ (2 files)
└── typescript/ (5 files)
```

**优势**: 对于配置目录等结构清晰但文件较多的场景,既保留了目录结构信息,又避免了文件列表的 Token 浪费。

## 🔧 参数组合示例

### 组合 1: 默认智能模式

```bash
python tools/py/project_scanner.py --exclude-standard
# 自动评估复杂度,应用最优策略
```

### 组合 2: 强制完整输出

```bash
python tools/py/project_scanner.py --no-adaptive
# 无论项目多大,都输出完整树
```

### 组合 3: 自定义省略策略

```bash
python tools/py/project_scanner.py --limit-items 20 --advanced-dir-threshold 30
# 每目录显示 20 个项目,子目录数 ≤ 30 时保留所有目录名
```

### 组合 4: 手动指定复杂度

```bash
python tools/py/project_scanner.py --complexity-override medium --limit-items 15
# 强制使用中级策略,每目录显示 15 个文件
```

## ⚙️ 实现要点

### 核心流程

1. **第一遍扫描**: 快速生成摘要 (统计文件数、目录数、深度等)
2. **复杂度评估**: 根据文件总数确定复杂度级别
3. **策略应用**:
   - 如果用户指定 `--no-adaptive`,跳过策略,完整输出
   - 如果用户指定 `--complexity-override`,使用指定级别
   - 否则使用自动评估的级别
4. **第二遍扫描**: 根据策略生成树结构
5. **智能判断** (仅高级模式): 对每个目录判断子目录数量,决定是否应用智能保留

### 关键函数

- `scan_summary()`: 快速摘要扫描
- `assess_complexity()`: 复杂度评估
- `scan_project_adaptive()`: 自适应扫描
- `scan_project_limited()`: 高级模式限制扫描 (支持智能子判断)

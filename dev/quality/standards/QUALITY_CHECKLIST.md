# 快速质量检查清单

> **用途**: 提供快速检查清单,用于文档审查时逐项核对  
> **使用方式**: 打印或在屏幕上对照检查  
> **版本**: v1.0

---

## ✅ 五维度检查清单

### 📌 准确性 (Accuracy)

- [ ] 所有信息准确无误，无错误陈述
- [ ] 代码示例可正常运行，语法正确
- [ ] API/函数签名与实际代码一致
- [ ] 配置项、路径、参数值正确
- [ ] 所有链接有效，无断链
- [ ] 专业术语使用准确

### 📌 完整性 (Completeness)

- [ ] 所有核心概念都有说明
- [ ] 典型使用场景都有覆盖
- [ ] 按文档类型包含所有必需章节
- [ ] 重要概念都有代码示例
- [ ] 异常情况、边界条件有说明
- [ ] 前置知识、依赖明确列出

### 📌 一致性 (Consistency)

**术语一致**:

- [ ] 同一概念使用统一术语
- [ ] 专有名词大小写统一
- [ ] 缩写规范（首次全称+缩写）

**格式一致**:

- [ ] 标题层级正确（无跳级）
- [ ] 列表格式统一
- [ ] 代码块统一使用```语言标识
- [ ] 表格格式统一

**风格一致**:

- [ ] 语气统一（指导性/说明性）
- [ ] 人称统一（你/您/用户）

### 📌 可读性 (Readability)

**结构清晰**:

- [ ] 章节顺序符合认知逻辑
- [ ] 使用标题、列表区分层次
- [ ] 长文档有 TOC 目录
- [ ] 重点内容突出显示

**表述简洁**:

- [ ] 语言简洁，无冗余
- [ ] 段落长度适中（≤200 字）
- [ ] 句子清晰，无歧义
- [ ] 优先使用主动语态

**可视化**:

- [ ] 复杂流程有图表辅助
- [ ] 多维度对比使用表格
- [ ] 代码块有语言高亮
- [ ] 使用视觉标记（emoji、符号）

### 📌 可操作性 (Actionability)

**指令明确**:

- [ ] 操作步骤有序号
- [ ] 使用明确的动作动词
- [ ] 条件分支清晰
- [ ] 说明预期结果

**示例具体**:

- [ ] 代码示例完整可运行
- [ ] 关键代码有注释
- [ ] 文件路径具体
- [ ] 命令可直接复制

**降低门槛**:

- [ ] 列出前置条件
- [ ] 说明常见错误和解决方法
- [ ] 提供验证检查点

## 📋 按文档类型的特定检查

### 入口文档 (AI_ENTRY_POINT, INTRODUCTION)

- [ ] 文档索引完整，所有文档都被索引
- [ ] 每个文档的"何时使用"描述明确
- [ ] 工作流分派逻辑清晰
- [ ] 决策树/流程图准确

### 核心规范 (core/\*.md)

- [ ] 规则强制性明确（必须/应该/可以）
- [ ] 每条规则都有执行方法
- [ ] 提供检查清单或验证方法
- [ ] 覆盖典型和边缘场景

### 工作流 (workflows/\*.md)

- [ ] 步骤有序号且逻辑清晰
- [ ] 步骤间依赖关系明确
- [ ] 提供流程图
- [ ] AI 指令模板可直接使用
- [ ] 有异常处理和降级方案

### 指导文档 (guides/\*.md)

- [ ] 提供可运行的命令/代码
- [ ] 示例完整可用
- [ ] 从简单到复杂递进
- [ ] 提供实际使用场景
- [ ] 有常见问题 FAQ

### 模板 (templates/\*.md)

- [ ] 包含所有必需章节
- [ ] 占位符规范且含义明确
- [ ] 每个章节都有示例
- [ ] 可直接复制使用

## 🎯 快速评分

**9-10 分**: 所有检查项 ✅, 几乎无需改进  
**7-8 分**: 大部分 ✅, 1-2 个维度有小问题  
**5-6 分**: 3 个维度 ✅, 2 个维度有明显问题  
**3-4 分**: 多个维度有严重问题  
**1-2 分**: 大多数维度严重问题，需重写

## 💡 使用建议

### 审查前

1. 打印本清单或在第二屏幕显示
2. 准备标记工具（对照检查）

### 审查中

1. 逐项检查，标记 ✅ 或 ❌
2. 记录具体问题位置和描述
3. 标注优先级（高/中/低）

### 审查后

1. 汇总问题清单
2. 按优先级修复
3. 重新检查修复项

## 🚀 快速开始

### 作为开发者

1. 阅读 `INTRODUCTION.md` 了解框架
2. 复制框架到你的项目
3. 让 AI 读取 `AI_ENTRY_POINT.md`
4. AI 自动生成文档体系

### 让 AI 使用

```
请阅读 _documentation_framework/AI_ENTRY_POINT.md
然后为当前项目生成文档体系
```

AI 会自主完成：项目检测 → 策略决策 → 生成方案 → 等待审核 → 执行生成

### 🌟 核心优势（10 项）

1. **AI 自主决策机制完整** ⭐⭐⭐ - 最大亮点
   - 从项目检测 → 策略选择 → 方案生成 → 执行生成全流程自动化
   - AI 仅需阅读一个入口文件即可独立完成所有决策
2. **"方案优先"机制避免返工** ⭐⭐⭐

   - 强制生成可审核的方案,包含验证命令、代码依据、问题发现
   - 审核通过后才开始文档生成,避免大规模返工

3. **项目类型覆盖全面** ⭐⭐

   - 支持 11 种项目类型覆盖 95%场景
   - 每种类型都有详细的子文档推荐和关注点

4. **跨平台命令支持完善** ⭐⭐ (v2.1 增强)

   - 所有关键命令都提供 Windows/Linux/Mac 版本
   - 统计工具支持四级降级(tokei/cloc/fd/基础命令)

5. **进度记录机制保证恢复能力** ⭐⭐⭐

   - 强制使用进度记录,支持会话中断后恢复
   - v2.1 专门说明了 4 大价值(会话恢复/用户审核/质量保证/协作友好)

6. **问题发现机制主动风险管理** ⭐⭐

   - AI 主动发现代码问题、技术债务、架构隐患
   - 明确"不臆测"原则,不确定的记录到疑问事项

7. **复杂度因子智能调整** ⭐⭐ (v2.1 新增)

   - 考虑 Monorepo/微服务/混合语言/多租户等因素
   - 自动调整策略级别,更准确匹配项目复杂度

8. **故障降级决策机制完善** ⭐⭐ (v2.1 新增)

   - AI 自主处理故障,能继续则继续
   - 结束时汇总提醒用户,不频繁打断

9. **模板体系完整实用** ⭐⭐

   - 14 个模板文件覆盖所有生成场景
   - 包含核心模板和可选模板

10. **文档职责分离清晰** ⭐⭐
    - AI 入口和人类指南完全分离
    - 降低了使用门槛

# AI 自检项清单

> **适用范围**: 所有工作流路径  
> **用途**: 确保 AI 生成的方案和文档符合质量标准  
> **更新日期**: 2025-12-19

---

## 📋 生成方案时的自检项

在生成 `generation_plan.md` 和 `project_analysis_report.md` 时，必须确保：

### 数据验证

- [ ] **所有统计数据都有验证命令**
  - 示例：文件数、代码行数、目录结构等
  - 每个数据都应提供可执行的验证命令
  - 用户可以通过命令自行验证数据准确性

- [ ] **所有代码示例都有文件路径和行号**
  - 格式：`src/main.ts:15-20`
  - 避免使用"类似这样的代码"等模糊描述
  - 确保代码示例来自实际项目文件

- [ ] **所有架构特点都有代码依据**
  - 不能臆测架构设计
  - 每个架构特点都应引用具体的代码文件
  - 提供验证命令让用户确认

### 问题记录

- [ ] **不确定的地方都记录到疑问事项**
  - 使用 🔵 标记疑问事项
  - 明确说明为什么不确定
  - 提供可能的验证方法

- [ ] **发现的问题都分类记录**
  - 🔴 严重问题：影响核心功能或架构
  - 🟡 警告问题：需要注意但不致命
  - 🔵 疑问事项：需要用户确认
  - 💡 优化建议：改进建议

### 内容质量

- [ ] **没有使用占位符**
  - ❌ 禁止：`[待补充]`、`[TODO]`、`...` 等
  - ✅ 正确：提供实际内容或标记为疑问事项

- [ ] **没有臆测架构特点**
  - ❌ 禁止：基于常见模式推测
  - ✅ 正确：基于实际代码分析

## 📝 生成文档时的自检项

在生成 `dev_docs/` 下的所有文档时，必须确保：

### 方案执行

- [ ] **严格按照审核通过的方案执行**
  - 不得随意偏离方案中的子文档清单
  - 不得随意修改文档结构
  - 如需偏离，必须先说明原因并获得用户同意

- [ ] **所有数据来自方案中标注的实际代码**
  - 使用方案中提供的文件路径和行号
  - 不得使用方案中未验证的数据
  - 如发现方案数据有误，应先更新方案

### 文档结构

- [ ] **文档结构符合模板要求**
  - 使用对应的模板文件（`templates/` 目录）
  - 保持章节结构一致
  - 包含所有必需章节

- [ ] **代码示例完整可用**
  - 代码示例可以直接运行或理解
  - 包含必要的导入语句和上下文
  - 提供代码说明和注释

### 摘要与关联

- [ ] **摘要检查：所有文档包含符合 YAML 规范的摘要** ⭐
  - 必须包含 YAML frontmatter
  - 格式符合 `core/SUMMARY_FORMAT_SPEC.md`
  - 所有必需字段都已填写

- [ ] **关联检查：`related_files` 字段准确无误** ⭐
  - 列出文档中提到的所有代码文件路径
  - 使用相对路径（从项目根目录开始）
  - 用于自动更新检测（增量更新时使用）

### 进度记录

- [ ] **进度记录：已创建并持续更新 generation_progress.md** ⭐
  - 在开始生成前，必须先创建进度文件
  - 使用模板：`templates/PROGRESS_TEMPLATE.md`
  - 固定路径：`dev_docs/_analysis/generation_progress.md`

- [ ] **进度同步：每完成一个文档立即更新进度状态** ⭐
  - 完成一个文档后，立即标记为 `[x]`
  - 更新进度计数（X/N）
  - 记录完成时间

### 偏离处理

- [ ] **如偏离方案，先说明原因**
  - 在文档中明确标注偏离点
  - 说明偏离的原因和依据
  - 获得用户确认后再继续

## 🔍 自检流程

### 方案生成后的自检

```markdown
## 自检清单

### 数据验证
- [x] 文件数统计：150 个文件
  验证命令：`fd -t f | wc -l`
- [x] 代码行数：12,500 行
  验证命令：`tokei`
- [x] 主要语言：TypeScript (65%)
  验证命令：`tokei --sort lines`

### 代码示例
- [x] 路由配置：`src/router/index.ts:10-25`
- [x] 状态管理：`src/store/index.ts:5-15`

### 问题记录
- 🔴 严重问题：0 个
- 🟡 警告问题：2 个
- 🔵 疑问事项：3 个

### 内容质量
- [x] 无占位符
- [x] 无臆测内容
```

### 文档生成后的自检

```markdown
## 自检清单

### 方案执行
- [x] 按方案生成了 8 个子文档
- [x] 文档结构符合模板

### 摘要与关联
- [x] 所有文档包含 YAML frontmatter
- [x] `related_files` 字段已填写

### 进度记录
- [x] 进度文件已创建
- [x] 进度状态：8/8 完成
- [x] 完成时间已记录
```
